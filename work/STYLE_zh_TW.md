# 繁體中文（台灣）翻譯規範

`work/zh_TW/base.json` 由簡體中文譯文自動轉換而成（`tools/zh_tw.py`），修正寫在 `work/zh_TW/fix_*.json`。

- 用字與用語採台灣習慣（程式、資訊、螢幕、檔案、登入、選單、滑鼠、機率、透過），語氣自然，去除大陸用語與過多的兒化音（一點兒 → 一點、大伙兒 → 大家）。
- 稱呼玩家用「你」。引號用「」與『』。不使用破折號和「 - 」。
- 轉換錯字要改正：後/后、裡/里、乾/幹/干、復/複/覆、制/製、系/係/繫、準/准、穀/谷、鬆/松、只/隻、發/髮、遊/游、徵/征、捲/卷、佔/占、麵/面、著、於、並、鬍鬚、夥、捨、迴、噁心、透過/通過（經過某處用「通過」）、儲存/保存（完好保存用「保存」）、連線/連接（網路用「連線」）。
- 佔位符 {…}、標籤 […]、換行數、首尾空格不變。
- 人名、地名維持轉換後的寫法，全部一致。
